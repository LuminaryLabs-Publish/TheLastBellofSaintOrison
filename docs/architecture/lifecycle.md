# Lifecycle

Install once per engine. Domain resources are initialized by Nexus initWorld. The parent owner is the only state writer. Service factories do not start timers. The player action Kit drains at most 64 pending semantic commands per tick. Threat owns the single pressure system; sleeping locations have no systems of their own.

Start resets all five domain resources, clears session receipts, enters the first Scene, registers that location's Objects, runs arrival and mounts its investigation graph. Re-entry preserves progress and immutable prior choices, rebuilds Objects and reconstructs the finite waits from discovered clues and solved status.

Pause, panels, settings and suspension stop pressure. Voluntary or forced retreat preserves evidence and runs recovery. Departure requires a finished puzzle and native Sequence authorization before Scene travel. Dispose cancels/unmounts runners, clears receipts and input, empties Objects and suspends play. Presentation/provider disposal separately releases derived resources; domain resources retain engine lifetime.

Save restore validates all domains and cross-domain consistency before any write. The current synchronous owner commit cannot yield between domains. Logical waits are rebuilt; callback handles are never serialized.
