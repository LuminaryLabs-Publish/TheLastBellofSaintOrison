# Target Composition

The main entry re-exports createModularGame. Foundation Kits provide Scene, Input, Interaction, Object, Asset and Presentation. The campaign composition installs five product owners, sixteen Service Kits, fifteen location Kits, finite operations and the save/command integrations. Location packages have no duplicate progress resource.

Commands drain in Runtime's input phase. Threat advances in simulate. Interface projection runs in resolve and requests location/camera/audio projection. Rendering consumes the same immutable packets as before. All authored content is in location content/*.json and content/shared or content/progression. content/campaign.js is generated; it is not a second authoring destination.

The game still uses the pinned event-driven Sequence node runtime. It does not claim the proposed future root n:sequence API, arbitrary dynamic AST execution, job scheduling, final production assets or measured three-hour playtime.
