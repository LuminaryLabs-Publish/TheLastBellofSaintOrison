# Pressure and Warning Contract

**Target specification; runtime implementation pending.**

Threat owns elapsed/exposure and escalation. Location content selects parameters and warning cues; it does not install another timer. Begin from current room allocations, then tune from play evidence. One room budget spans its encounters; entering a close view does not secretly reset it.

Proposed stages: below 50% stable; at 50% warning; at 80% critical; at 100% controlled retreat. Every stage has a named visual icon and caption equivalent. Stage changes cannot lock the only exit, remove essential proof or make a previously valid ending impossible by silently consuming an item.

Advance during active exploration/manipulation. Pause for menus, explicit hints, user journal reading, required instructional captions and consequence decisions. Normal object focus alone does not pause unless it is presenting required information. Gentle extends time; Story removes deadline pressure while preserving authored warning demonstrations. Exact new mode values require a Threat task and player testing.

At retreat, cancel uncommitted input, restore mechanisms to their last stable state and use the existing safe location behavior. A held control must not complete during pause. Wrong-attempt penalties, if retained from the source, must be disclosed and bounded; initial safe demonstrations carry none. Optionality is never permission to erase required evidence.

Passive warning captions do not pause the clock. Only deliberately opened required explanations, menus or journals do. Town Square and Exit Road are quiet epilogues: no percentage escalation applies to their zero-pressure state. After choosing an optional recovery, physical execution may resume pressure; choice preview itself never expires.
