# Consequences and Ending Map

**Target design specification; not implemented gameplay.**

The existing ending decision is committed at Well Chamber. Square and Road resolve custody and responsibility; they do not choose a second ending.

## Exact existing eligibility
The source `witnessAvailable()` requires inventory register, archive and relay; knowledge names-second-four; and absence of relayBroken. First-four verification is represented by obtaining register. The source does not separately require relayIntact=true. Target design preserves that predicate rather than accidentally adding another save-breaking condition.

| Ending | Required condition at confirmation | Physical meaning | Persistent consequence |
|---|---|---|---|
| Witness | Existing predicate plus released core/primary progression | Distribute names and inspectable proof over the intact public line | A sole vessel is no longer necessary |
| Silence | Core released; source progression satisfied | Isolate the line; outer, inner, outer on braces | Voices stop; proof remains limited to held records |
| Vessel | Core released; explicit voluntary confirmation | Mara offers her own copied pattern | The burden continues and remembrance becomes unreliable |

## Local choices that matter
Tower preserve/break is irreversible after confirmation; break disables Witness. Archive photo/original affects access to original proof; skipping it never blocks all endings. Chapel release/line controls actual character location. Market marker and tunnel chalk help the return but never replace permanent route signs. Public copies/custody remain possible after all endings without asserting public transmission happened for Silence or Vessel.

## Confirmation contract
Selecting an option previews it. Confirmation is a distinct action. Pause pressure during the consequence explanation, disable controls for unmet conditions with the exact missing requirements, and never default an unavailable option to another ending. Duplicate requests return the committed result. Save/reload cannot create a second intervention. The source already uses explicit confirmation for endings and relay break; new presentation must preserve those guards.
