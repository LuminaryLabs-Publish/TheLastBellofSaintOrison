# Optional Lore and Journal Index

**Target design specification; not implemented gameplay.**

Full source prose remains in the current location observation and dialogue JSON. This design does not delete it. Runtime implementation should retain it as named journal entries with location, object and discovery source, not open a full-screen paragraph after every click.

| Material | Essential delivery | Optional depth |
|---|---|---|
| Gate notice | Two-bell demonstration; blank-badge cutaway | Full warning wording and maintenance scratches |
| Visitor book | Elian, café, wave and time visible together | Evacuation carbon layers |
| Café cassette | Gull/two-bell comparison and private phrase caption | Full recording and relay cable account |
| Apothecary | Test reactions and protection limit | Clinical note and batch history |
| School identities | Paired seals and retained aliases | June’s permitted drawing; private margin remains closed |
| Archive order | Clinical/Oxygen/02:13 and original-vs-photo distinction | Full signed order and institutional explanation |
| Chapel confession | Short statement that the vessel is not a child | Vale’s complete confession and responsibility |
| Parish family letter | Brief essential fact about burning the papers | Full letter and optional personal response |
| Well methods | One explicit consequence and requirement preview each | Detailed explanation of the pattern and unclaimed voices |
| Epilogue | Physical custody and departure action | Full reflection and ending prose |

Optional does not mean silently unavailable. Journal entries stay retrievable after discovery; replay does not award clues a second time. Reading the optional entry pauses danger while open under the shared pressure policy. Accessibility transcripts can be longer than aesthetic caption targets when accuracy requires it.
