# Character Movement and Knowledge Map

**Target design specification; not implemented gameplay.**

Mara Venn is the player. Elian is her missing sister, who entered voluntarily to interrupt the relay. The original cassette contains a gull and two bells, plus the private phrase “The long breathing.” Café imitation is not proof of Elian’s presence. The town contains twelve erased hospital identities; this adaptation verifies eight. The separate thirteenth channel is the vessel.

|---|---|---|
| Gate through Archive | Not yet independently confirmed by Mara | Original recording or explicitly uncertain signal; no companion model |

| Chapel line choice | Protected archive-line station | Remote speech; no physical companion beside Mara |

| Return Ascent, remote | Station, then explicitly described physical route if assistance is completed | Line confirmation; no teleportation |
| Square and Road | Confirmed safe only when the actual branch supports it | Use verified presence or explicitly unresolved status |

June’s reflection in School preserves a chosen privacy boundary. Father Vale’s confession identifies Silas and institutional responsibility; neither is converted into a new objective owner or required follower. The reconciliation retains Mara’s admission about burning Father’s papers and Elian’s response without automatic forgiveness.

Every new line records speaker, scene, source of knowledge and branch condition. A writer must not let Elian know evidence Mara has not shared, or portray confirmed rescue solely because a friendly voice was heard. Exact performed voice casting and character animation remain production tasks.
