# Observation and Action Design Standard

**Target specification; runtime implementation pending.**

The player first sees a situation, then acts and receives evidence. A closed gate should resist at a visible catch; opening it should move that catch. A successful flag without an observable response is incomplete presentation.

Each required rule needs an obtainable demonstration before danger depends on understanding it. Gate teaches two bells and the dark phase using a protected trolley. Apothecary demonstrates resin behavior with reusable samples. A character may lie about the story; controls and safety indicators must remain consistent with their documented meaning.

Review each clue from the first available viewpoint: can it be found without reading the specification, is its relationship to a control visible, and is the result distinguishable from idle? Identify which action reveals each fact; proximity alone does not authorize granting all room knowledge.

Object selection opens a focused view or local caption, not a default full-screen text interruption. A short reaction can reinforce an observed fact. Long narrative belongs in optional journal replay. Existing story facts and names remain precise even when their delivery changes.

Completion requires both a valid owner receipt and its visible consequence. A presentation animation never independently decides whether a mechanism is solved.
