## Player purpose

Mark a recognizable return crossing.

## Entry and first impression

Arrive from closed-cafe. Complete MS-01 first. Also complete the second required encounter before departure; this optional encounter never supplies its prerequisites.

A repair parcel rests on a ledge accessible from the secured freight opening.

## Objects and controls

- tether: pull parcel onto ledge
- parcel-flap: inspect repair marker
- marker: tie to return eyelet

## Obtainable clues

- The parcel carries an existing repair-stall marker, not a new quest item.
- A return arrow on the eyelet points back through the secured shutter.

## Exact action sequence

1. Pull the parcel along its existing tether from the safe ledge.
2. Unfold the pale repair marker and compare its arrow with the return eyelet.
3. Tie the marker to that eyelet; the crossing gains a persistent landmark.

## Wrong attempts and assistance

Release of the tether lets the parcel rest on a lower stop, never beyond recovery.

Hints progress only on request:

1. Use the tether from shelter.
2. The marker belongs at the return eyelet.
3. Tie it where it can be seen from the reverse direction.

## Completion

Optional marketSafe outcome recorded; lantern acquisition never depends on the parcel.

## Supported alternatives

The exact sequence above is the supported logical solution. Pointer, keyboard and assisted controls are equivalent input paths, not alternate story outcomes. Skipping is supported and retains all mandatory progression.

## Pressure and accessible operation

Use the shared room exposure budget, initially the source allocation of 145 seconds, not a fresh full timer per encounter. Advance only during active world manipulation after a safe clue demonstration. At 50% show the room warning with a stable warning icon: “A shutter slams at the far end of the market.” At 80% show its critical caption and distinct double-border marker: “The counterweight begins to slip; the open crossing narrows.” At the room limit release held controls safely and use the established retreat: You withdraw to the freight alcove, beyond the shutter’s travel. Its safety stop catches. Never destroy required evidence. An optional detour may cost active time, but skipping it changes no required gate. Menus, hints, required captions/consequence explanations and user-requested journal reading pause exposure; normal close inspection keeps the world active unless a required explanation is on screen. Source allocations are tuning starting points, not measured encounter durations. Passive warning icons and ambient captions do not pause time; only an explicitly opened required explanation does.

Controls tether, parcel-flap, marker must each have a focusable name and a visible response. Pointer drag/rotation has discrete click controls and keyboard previous/next/confirm equivalents. Holds offer press-to-latch and press-to-release assistance; release on blur, pause or scene exit cannot commit a destructive action. Caption all significant sounds; preserve symbol or shape distinctions independently of color. Replay demonstrations by user-stepped stages when timing is assisted. Keep clue text at supported large scale with paging inside the inspection area, and retain a stable back/exit action. Reduced motion replaces continuous movement with labelled state changes while preserving clue order.

## Save, reset and cancellation

Proposed Investigation-owned logical record: encounterId=MS-03, definitionVersion=1, confirmedStep (0 through 3), completed, and a validated control-value record keyed only by tether, parcel-flap, marker. Decision records additionally store a preview selection separately from the single Narrative/Campaign commit. This is a proposed schema extension, not an existing installed API. Snapshot logical state plus owning-domain effects at one safe commit boundary. Never save DOM nodes, callbacks, drag pointers, audio handles, frame timestamps or an animation position as authority. On restore, reconstruct controls from confirmed state and replay only noncommitting feedback; never award a reward again. An interrupted unconfirmed drag/hold returns to its last stable detent. A wrong attempt resets only the local unsolved control sequence specified above; verified clues, items, primary completion and committed choices remain. Validate the whole snapshot and definition version before replacing any live owner; an unknown version leaves the current session unchanged. Entry/exit removes input subscriptions, stops local audio and cancels uncommitted operation receipts. Retry preserves original branch commitments and can always return to the named shelter.
