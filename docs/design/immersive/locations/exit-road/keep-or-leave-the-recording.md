## Pressure and accessible operation

Quiet epilogue: no exposure countdown, automatic escalation or forced retreat. The player can replay evidence, consider choices and use accessibility controls without urgency. Any distant bell or light change is a consequence cue, not a new timed threat. The existing ending remains committed. Pausing and saving are always available.

Controls satchel-slot, copy-envelope, first-line must each have a focusable name and a visible response. Pointer drag/rotation has discrete click controls and keyboard previous/next/confirm equivalents. Holds offer press-to-latch and press-to-release assistance; release on blur, pause or scene exit cannot commit a destructive action. Caption all significant sounds; preserve symbol or shape distinctions independently of color. Replay demonstrations by user-stepped stages when timing is assisted. Keep clue text at supported large scale with paging inside the inspection area, and retain a stable back/exit action. Reduced motion replaces continuous movement with labelled state changes while preserving clue order.

## Save, reset and cancellation

Proposed Investigation-owned logical record: encounterId=ER-02, definitionVersion=1, confirmedStep (0 through 3), completed, and a validated control-value record keyed only by satchel-slot, copy-envelope, first-line. Decision records additionally store a preview selection separately from the single Narrative/Campaign commit. This is a proposed schema extension, not an existing installed API. Snapshot logical state plus owning-domain effects at one safe commit boundary. Never save DOM nodes, callbacks, drag pointers, audio handles, frame timestamps or an animation position as authority. On restore, reconstruct controls from confirmed state and replay only noncommitting feedback; never award a reward again. An interrupted unconfirmed drag/hold returns to its last stable detent. A wrong attempt resets only the local unsolved control sequence specified above; verified clues, items, primary completion and committed choices remain. Validate the whole snapshot and definition version before replacing any live owner; an unknown version leaves the current session unchanged. Entry/exit removes input subscriptions, stops local audio and cancels uncommitted operation receipts. Retry preserves original branch commitments and can always return to the named shelter.
