# Release the Gate Latch

**TG-02 · puzzle · required · specified, not implemented**

## Player purpose

Open the gate without supplying a living name.

## Entry and first impression

Arrive from new game with Elian’s cassette. Complete TG-01 first.

Named badges make a test striker speak; the blank badge advances an unvoiced latch tooth.

## Objects and controls

- badge-slot: select or place the blank badge
- tension-handle: pull to the marked stop
- catch: lift while the handle is latched

## Obtainable clues

- A cutaway test track shows named badges trapped under a speaking-mouth jaw.
- The blank badge passes under that jaw and bears the same notch as the intake-key drawer.

## Exact action sequence

1. Slide the blank badge through the cutaway; the mouth jaw stays closed.
2. Seat that badge in the real slot; a latch tooth withdraws.
3. Pull the tension handle to its physical stop, then lift the catch.
4. The gate unlocks and the drawer dispenses the existing intake key once.

## Wrong attempts and assistance

A named badge springs back before transmission; a loaded catch cannot lift. No identity is committed by an exploratory click.

Hints progress only on request:

1. Watch which badge bypasses the mouth jaw.
2. The empty badge is an intentional entry.
3. Blank badge, pull handle, lift catch.

## Completion

Blank entry selected, latch released and intake key granted once; crossing remains subject to TG-01.

## Supported alternatives

The exact sequence above is the supported logical solution. Pointer, keyboard and assisted controls are equivalent input paths, not alternate story outcomes. Different persistent outcomes exist only where the listed decision explicitly offers them; no extra solution is implied.

## Save, reset and cancellation

Proposed Investigation-owned logical record: encounterId=TG-02, definitionVersion=1, confirmedStep (0 through 4), completed, and a validated control-value record keyed only by badge-slot, tension-handle, catch. Decision records additionally store a preview selection separately from the single Narrative/Campaign commit. This is a proposed schema extension, not an existing installed API. Snapshot logical state plus owning-domain effects at one safe commit boundary. Never save DOM nodes, callbacks, drag pointers, audio handles, frame timestamps or an animation position as authority. On restore, reconstruct controls from confirmed state and replay only noncommitting feedback; never award a reward again. An interrupted unconfirmed drag/hold returns to its last stable detent. A wrong attempt resets only the local unsolved control sequence specified above; verified clues, items, primary completion and committed choices remain. Validate the whole snapshot and definition version before replacing any live owner; an unknown version leaves the current session unchanged. Entry/exit removes input subscriptions, stops local audio and cancels uncommitted operation receipts. Retry preserves original branch commitments and can always return to the named shelter.
