# Return Ascent — Location Design

**Target specification; existing playable content is unchanged.**

## Purpose and geography

Use the verified return route and make it back above ground.

Arrival from well-chamber; departure to town-square. Reuse the current authored environment and entry/exit identities. New controls occupy reachable close-inspection views rather than requiring new locomotion.

## First readable situation

Familiar plates remain; lighting differs with the relay and intervention state.

## Authored interaction zones

- Zone 1: **Identify the Surviving Route**. Read the return path under the chosen ending’s conditions. Controls: return-plate, emergency-line, route-marker. A wide view must expose its location before a close view is required.
- Zone 2: **Release the Escape Gates**. Open the upper exit using a mechanism that survives all endings. Controls: manual-handles, gate-latch, upper-stair. A wide view must expose its location before a close view is required.
- Zone 3: **Retrieve the Endangered Evidence**. Choose whether to spend time helping Elian secure her route and copies. Controls: line-switch, duplicate-pouch, leave-control. A wide view must expose its location before a close view is required.

## Spatial constraints

Keep the exit and named shelter visible from the primary interaction zone. No required control may sit behind a permanently locked optional object. Reused return environments keep their landmark positions; state variants change lighting and access, not the meaning of established navigation symbols. Initial blockout uses labelled zones; final dimensions and camera framing need a measured asset/layout review.
