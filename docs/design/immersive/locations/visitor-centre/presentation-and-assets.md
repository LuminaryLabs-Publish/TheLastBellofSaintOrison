## Shared requirements

Use metres and the current provider convention only after checking the existing binding. State pivots, handedness, interaction proxy, near-camera legibility and loading behavior explicitly in each asset task. No imported file may change domain state. Every important sound needs a synchronized visible or captioned equivalent. Motion must stop or simplify under reduced-motion settings. Missing assets preserve usable controls through labelled proxy geometry. Final rights/provenance remain open until source assets exist.
