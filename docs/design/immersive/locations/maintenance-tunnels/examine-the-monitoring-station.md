## Pressure and accessible operation

Use the shared room exposure budget, initially the source allocation of 125 seconds, not a fresh full timer per encounter. Advance only during active world manipulation after a safe clue demonstration. At 50% show the room warning with a stable warning icon: “The voice behind you takes the sound of your own footsteps.” At 80% show its critical caption and distinct double-border marker: “The far light dies. Your chalk marks remain visible.” At the room limit release held controls safely and use the established retreat: You return to the pump niche using the pipes you can touch. The voice keeps walking beyond it. Never destroy required evidence. An optional detour may cost active time, but skipping it changes no required gate. Menus, hints, required captions/consequence explanations and user-requested journal reading pause exposure; normal close inspection keeps the world active unless a required explanation is on screen. Source allocations are tuning starting points, not measured encounter durations. Passive warning icons and ambient captions do not pause time; only an explicitly opened required explanation does.

Controls monitor-switch, plate, chalk-holder must each have a focusable name and a visible response. Pointer drag/rotation has discrete click controls and keyboard previous/next/confirm equivalents. Holds offer press-to-latch and press-to-release assistance; release on blur, pause or scene exit cannot commit a destructive action. Caption all significant sounds; preserve symbol or shape distinctions independently of color. Replay demonstrations by user-stepped stages when timing is assisted. Keep clue text at supported large scale with paging inside the inspection area, and retain a stable back/exit action. Reduced motion replaces continuous movement with labelled state changes while preserving clue order.

## Save, reset and cancellation

Decision records additionally store a preview selection separately from the single Narrative/Campaign commit. This is a proposed schema extension, not an existing installed API. Snapshot logical state plus owning-domain effects at one safe commit boundary. Never save DOM nodes, callbacks, drag pointers, audio handles, frame timestamps or an animation position as authority. On restore, reconstruct controls from confirmed state and replay only noncommitting feedback; never award a reward again. An interrupted unconfirmed drag/hold returns to its last stable detent. A wrong attempt resets only the local unsolved control sequence specified above; verified clues, items, primary completion and committed choices remain. Validate the whole snapshot and definition version before replacing any live owner; an unknown version leaves the current session unchanged. Entry/exit removes input subscriptions, stops local audio and cancels uncommitted operation receipts. Retry preserves original branch commitments and can always return to the named shelter.
