# Object Focus and Close Inspection

**Target specification; runtime implementation pending.**

Selecting a world object opens a close view that preserves the room’s spatial context and a stable return control. Highlight the selected affordance, not every object simultaneously. Each physical control needs a named focus target, visible hit bounds in review tooling and a keyboard-equivalent action.

Place captions beside or below the inspected object without covering its clue. At large text scale, reflow or page inside the inspection surface. Do not shrink essential text, hide the exit or require dragging a panel to reach a control. An object inventory card can be a fallback access path when its world proxy is difficult to see.

Modal confirmations block underlying controls and clear their active highlight. Close-view transitions themselves do not commit an action. After cancel or restore, focus returns to the initiating object or a predictable safe default. Canvas fallback must expose all meaningful controls even when the 3D camera cannot be reproduced.
