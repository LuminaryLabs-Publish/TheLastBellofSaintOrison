# Pressure Assistance Settings

**Target specification; runtime implementation pending.**

Provide normal, extended and untimed exposure modes through the owning Threat contract, with saved preferences. Keep puzzle logic identical; assistance changes the time to observe and operate it. Normal game speed is not a prerequisite for seeing the story.

Offer stepped demonstrations, toggle holds and discrete rotation/placement controls. Focus loss pauses pending manipulation and releases pointer capture; restoring focus must not suddenly confirm an irreversible choice. Required explanations pause pressure in every mode.

Reduced motion, reduced flashes and muted audio each retain a usable representation of every clue. Avoid relying on a nearly black screen as the only critical warning. A stable shelter action and warning icon remain visible under darkness effects.

Exact tuning values and device-specific mappings require implementation and human review. This specification does not certify accessibility or physical controller support.
