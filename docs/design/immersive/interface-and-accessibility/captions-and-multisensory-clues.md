# Captions and Multisensory Clues

**Target specification; runtime implementation pending.**

Every consequential sound has a visible or text equivalent: bell strokes have drum notches; the radio has a trace; a moving voice has source captions; a mechanical failure has a stable indicator. Color pairs also differ by shape, placement or label. Reduced motion uses deliberate state steps instead of removing the clue.

Captions identify source and action, for example [Gate bell: second stroke], rather than only mood. A speech transcript preserves exact names and the private phrase. Do not reveal an answer that the audio version does not contain, or omit timing/order necessary to solve the same puzzle.

Let players replay and step through essential demonstrations. Keep subtitles and interaction labels distinct so one cannot be mistaken for a clickable choice. Test muted audio, color assistance, large text and reduced effects together, not only one setting at a time. Screen-reader support is a separate unimplemented surface; Canvas captions alone do not establish it.
