# Location Flow Template

**Specification package; no runtime or Drive changes.**

Record the room identity, source revision, previous/next location, incoming item/knowledge state and existing primary gate. List encounters by stable ID and mark required, optional and permissible parallel inspection. Describe the exact moment the legacy primary can complete and each reward can be granted.

List every original departure ID, resulting flag/item/ending and the common next destination. Preserve revisit rules and already-committed choices. Separate an optional encounter completion from the room’s single departure choice.

For each dependency, name its producer and consumer. Reject cycles such as requiring prepared resin to learn the clue needed to obtain resin. Explain safe recovery when a player leaves a control half-operated. Note character presence branches and whether speech is recorded, remote or in person.

Acceptance: trace a minimal path, all local alternatives and the highest-risk incoming states. The next room must receive exactly the necessary state with no hidden grants from entry narration.
