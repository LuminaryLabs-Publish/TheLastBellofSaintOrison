# Evidence index

- `tests.txt`: complete scenario suite, including three ending routes and each immediate branch.
- `render-results.json`: 95 frame receipts from the actual Nexus composition and shared CPU Vulkan scene/UI renderer, including fifteen rooms and sixty close views at enlarged panel text.
- `rooms-contact.png`, `close-views-1.png` through `close-views-3.png`: inspected overview/contact sheets. Repeated prop/control presentation and final art remain open production findings.
- `interaction-before.json`, `interaction-after.json`, `interaction-inputs.json`: two-clue acquisition through canvas hit testing into Nexus Input. The associated saved MP4 is 10 seconds/24fps/1280×720; `video-validation.json` verifies frame integrity and media metadata.
- `source-manifest.json`: rendering candidate SHA-256 inputs. `final-source-manifest.json` records final inputs; `capture-source-comparison.json` explains the two nonvisual changes after recording.
- `tick-profile.json`: isolated Node tick-plus-packet observation, not a GPU frame-rate benchmark.
- `build.txt`, `linux-package.txt`, `windows-package.txt`: production bundle and package assembly logs. Installed launch remains unverified.
- `clean-install.txt`: dependency installation from the committed lockfile.

Large frame sequences and binaries are excluded from Git history. Reproduce them with the commands in the review protocol. Never present these headless results as browser/OS input, audio acceptance, human comprehension, target hardware performance or Steam approval.
